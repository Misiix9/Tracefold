# Tracefold quick start / Rövid útmutató

## Magyar

A Tracefold helyben tárolja a projekteket. Használatához nem szükséges fiók vagy alkalmazásszerver. A kezelőfelület alapértelmezett nyelve magyar; a **Beállítások és helyreállítás → Nyelv** mezőben válthatsz angolra. A saját feljegyzéseid szövege nem változik.

1. A projektválasztóban hozz létre projektet, vagy kezdj a beérkező jegyzetek között.
2. A **Gyorsjegyzet** gombbal rögzítsd, mit próbáltál és mi történt. A szerkesztő automatikusan ment; ellenőrizd a **Helyben mentve** állapotot.
3. Az **Észrevételek** alatt dokumentáld a lépéseket, a tényleges és az elvárt működést, a környezetet, a súlyosságot és az ismételt tesztelés eredményét.
4. Csatolj képeket vagy más bizonyítékokat. A **Rögzítés** a rendszer képernyőkép-választóját nyitja meg; a rendszer engedélye szükséges lehet. A képszerkesztőben jelölhetsz, vághatsz és kitakarhatsz.
5. A **Sablonok**, **Tesztesetek**, **Tesztfuttatások** és **Lefedettség** nézetekkel készíts ismételhető tesztelési folyamatot.
6. A **Jelentések** nézetben válassz jelentéstípust, ellenőrizd az előnézetet, majd exportálj PDF, DOCX, HTML, Markdown, CSV, JSON vagy hordozható projekt formátumban.

A privát feljegyzések kimaradnak a biztonságos megosztásból. A teljes biztonsági mentés viszont privát tartalmat és eredeti bizonyítékokat is tartalmaz: csak megfelelő helyre mentsd. A beállítások között készíthetsz és exportálhatsz mentést; a visszaállítás külön projektmásolatot hoz létre.

A telepített verzió a beállításokban látható. Ha elérhető új, kompatibilis kiadás, a Beállítások feletti elválasztó fölött megjelenik a lila frissítési gomb. A letöltés és telepítés az alkalmazáson belül történik. A frissítés menti a munkát és helyreállítási mentést készít.

## English

Tracefold stores projects locally. No account or application server is required. Hungarian is the default; change **Settings & recovery → Language** to English. Your own notes remain in their original language.

1. Create a project using the project selector, or start in the inbox.
2. Use **Quick note** to record what you tried and what happened. Changes autosave; confirm **Saved locally** before leaving.
3. Use **Findings** for reproduction steps, actual and expected behavior, environment, severity and retest results.
4. Attach evidence, or use **Capture** to open the operating system's screenshot chooser. Screen Recording permission may be required. Annotate, crop and redact images in the evidence editor.
5. Use **Templates**, **Test cases**, **Test runs** and **Coverage** for repeatable testing.
6. Use **Reports** to choose a report purpose, review the preview and export PDF, DOCX, HTML, Markdown, CSV, JSON or a portable project.

Private notes are excluded from safe sharing. Full backups include private content and original evidence; store them appropriately. Settings provides backup creation, file export and restoration. Restoring creates a separate project copy.

Settings shows the installed version. A purple update action appears above the divider preceding Settings only when a newer compatible release is available. Download and installation happen inside Tracefold after saving work and creating recovery backups.
