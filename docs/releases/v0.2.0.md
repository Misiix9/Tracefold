# Tracefold v0.2.0

Tracefold 0.2.0 introduces the first real plugin platform foundation and the Discovery plugin integration.

## Highlights

- Plugin management workspace for install, enable, disable, open, stop, update-by-reinstall, and removal.
- Loopback web plugin runtime with host-owned runtime state and HTTP health checks.
- Persistent plugin data stored separately from installed plugin code.
- Staged plugin installation with package/path/manifest validation and atomic replacement rollback.
- Streaming plugin package extraction with bounded per-file and total unpacked sizes.
- Plugin lifecycle cleanup on stop, replacement, main-window close, and application exit.
- Collision-free plugin window labels.
- Browser preview safely gates native plugin functionality.
- Hungarian localization for the plugin UI and errors.
- Discovery plugin package documentation and installation support.
- Verified signed updater artifacts and a generated `latest.json` feed are required before publication completes.

## Security model

Plugins in this beta are **trusted local code**. They run with the same OS-user privileges as Tracefold and are not sandboxed by Tracefold. Install only packages you trust. Declared capabilities are metadata for transparency in 0.2.0, not OS-level permission enforcement.

The host does enforce safe package paths, package size limits, loopback runtime declarations, health checks, host-owned runtime URLs, process-tree shutdown, and atomic replacement behavior.

## Compatibility

- Tracefold plugin manifest schema: `tracefold.plugin.v1`
- Plugin API: `1`
- Minimum Tracefold version for the first Discovery package: `0.2.0`

## Verification

The release merge was validated by GitHub Actions on Windows, macOS universal, and Linux. Frontend checks, unit tests, UI tests, Rust tests, signed updater artifact creation, and artifact uploads all completed successfully before this release publication trigger.
