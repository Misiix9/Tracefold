# Tracefold Discovery

This directory defines the first Tracefold plugin contract for Discovery.

The installable package is built from the Discovery project and validated against this manifest. The Tracefold host does not ship fake endpoint data or fake accounts.

## Package

`Tracefold-Discovery-v2.1.1.tracefold-plugin`

SHA-256:

`f46deb1896fc243a6fba337be2cf6fc2e30bddfbc92a8790640c8117c864dc54`

Install it from Tracefold's **Plugins** page with **Install plugin package**.

Discovery stores its settings, accounts, sessions, cases, crawler budgets, and results in its own persistent application data directory. Updating the plugin package does not replace that data.
